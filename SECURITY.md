# Security Policy

## Supported Versions

Cardea actively maintains security updates for the following versions:

| Version | Supported | Notes |
| :--- | :--- | :--- |
| `0.2.5` | :white_check_mark: | Current release |
| `< 0.2.5` | :x: | Unsupported; please upgrade to latest |

## Reporting a Vulnerability

We take the security of Cardea and agent skills seriously. If you discover a security vulnerability, please report it responsibly.

### Reporting Channels

- **GitHub Private Vulnerability Reporting:** When enabled on the repository, please submit reports directly via [GitHub Private Vulnerability Reporting](https://github.com/Leelaloo/cardea/security/advisories/new).
- **Public Issues Warning:** **DO NOT** report security vulnerabilities, exploit details, or potential security flaws in public GitHub Issues, Discussions, or Pull Requests.

> [!IMPORTANT]
> **Owner Setup Blocker:** A dedicated private security email address and automated private reporting channel are currently pending repository owner configuration. Until private vulnerability reporting is enabled in repository settings by the owner, please avoid posting sensitive vulnerability details publicly.

## Disclosure Policy & Process

1. **Receipt & Acknowledgement:** Once a private advisory is submitted, maintainers will review and confirm the vulnerability.
2. **Investigation & Fix:** Maintainers will triage the issue, assess severity, and develop a patch in a private branch.
3. **Release & Advisory:** A patched release will be issued alongside a published GitHub Security Advisory detailing the fix and credit to the reporter.
