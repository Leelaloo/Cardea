# Getting Support for Cardea

Welcome to Cardea support! Here is how to find help, ask questions, or report issues.

## Usage Q&A & Community Help

- **Documentation & Usage Guides:** Refer to the main [README.md](README.md) for quick-start instructions, command-line flags (`--json`, `--badge`, `--fix`, `--fix --apply`), and breakdown of static security checks.
- **GitHub Discussions:** When enabled on the repository, use GitHub Discussions for general usage questions, skill auditing advice, and community Q&A.

## Reporting Bugs & Requesting Features

If you encounter a bug or have a suggestion for improving Cardea:
- Check existing issues before opening a new one.
- Use the structured [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml) or [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.yml).

## Security Vulnerabilities

> [!IMPORTANT]
> Public issues and discussions are **not** for reporting security vulnerabilities in Cardea.
> For reporting security flaws or sensitive vulnerabilities, please refer to our [SECURITY.md](SECURITY.md) policy and use private vulnerability reporting when enabled.
