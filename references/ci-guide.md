# Running Cardea in CI

Cardea ships as a GitHub composite action. Every push and pull request
gets an audit, and your README badge stays honest because it is generated by
the same scanner — not hand-drawn.

## Quick start (in the skill's repository)

`.github/workflows/cardea.yml`:

```yaml
name: cardea
on:
  push:
    paths: ['**/SKILL.md', 'scripts/**', '.github/workflows/cardea.yml']
  pull_request:

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: Leelaloo/cardea/action@main   # TODO: replace OWNER when the repo is live (subdir action)
        with:
          path: .                    # folder containing SKILL.md
          fail-on-critical: 'true'  # red CI on DO-NOT-INSTALL, green otherwise
```

Behavior:
- The job fails on any critical finding (score is capped below 50 whenever
  `do_not_install` is true, so a red CI can never hide behind a green-looking
  number).
- `cardea-report.json` and `cardea-badge.svg` are uploaded as
  workflow artifacts on every run.
- The full report is attached to the job summary page.

## Fixes and badges in CI (optional)

Fixes applied on the runner are ephemeral: without a commit step they vanish
when the job ends. To persist `--fix --apply` changes and the badge, commit them back:

```yaml
      - uses: stefanzweifel/git-auto-commit-action@v5   # pin by SHA for supply-chain safety
        with:
          commit_message: 'cardea: apply safe fixes + refresh badge'
```

The uploaded `cardea-badge.svg` **artifact** is for audit records only —
GitHub artifact URLs need auth and expire, so they cannot be embedded in a
README. For a live README badge, commit the SVG (snippet above) and reference
the committed file:

```markdown
![Cardea score](../assets/demo/good-badge.svg)
```

The badge is a self-contained SVG (no external fonts or network calls), so it
renders on any marketplace, including ones that block shields.io embeds.

## Local equivalents

- One-off audit: `python3 scripts/cardea.py path/to/skill`
- With badge: `python3 scripts/cardea.py path/to/skill --badge score.svg`
- Apply safe fixes: `python3 scripts/cardea.py path/to/skill --fix`
- Machine-readable: `--json report.json` (score, band, do_not_install, all findings)
